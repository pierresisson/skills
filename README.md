# Codex Skills

Personal skills for Codex.

## Agent Factory

`agent-factory` provides explicit, cost-aware multi-agent orchestration. It routes strategic work to Sol, production engineering to Terra, and bounded exploration or authorized Git/GitHub execution to Luna.

Install it for the current user:

```sh
cp -R agent-factory ~/.codex/skills/
```

Invoke it explicitly:

```text
$agent-factory handle this task with an appropriate agent team
```

The skill does not activate implicitly.
